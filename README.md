# 通用外贸 B2B 获客与开发信

## 解决的问题

为不同产品和行业寻找海外企业客户，核验公开信息，对照 CRM 和历史名单查重，并准备有依据的个性化开发信及可追溯的客户资料。

## 安装方式

下载或克隆完整仓库，将目录命名为 `auto-b2b-outreach`，放到支持 Agent Skills 的环境中，例如项目的 `.agents/skills/auto-b2b-outreach/`，并保留 `SKILL.md`、`agents/`、`references/` 的结构。需要可用的公开网络检索与表格读写能力；CRM 数据和可选的本地邮件工具由使用者提供。

## 使用方法

告诉助手：“使用 $auto-b2b-outreach，为我的产品寻找某市场的经销商，筛选 20 家并准备开发信。”提供必要资料后，技能研究企业、核验公开渠道、只读查重并制作草稿。默认不联系客户；实际发送另须明确授权和本轮确认。

## 需要提供的输入

- 产品或服务、用途、已确认规格及商务条件；目标国家或城市、客户类型及期望数量。
- 如需完整查重，提供有权限的只读 CRM 入口或注明日期和覆盖范围的导出快照，以及相关历史名单。
- 可选：产品目录、公司官网、联系人模板、排除条件、署名、邮件语言和 CTA。缺少目标市场时会先提供候选市场供选择。

## 最终交付

默认交付三份独立工作簿：英文联系人与邮件、中文邮件翻译、客户信息与公开渠道；另有 `leads.json` 和 `research.md` 保存来源、候选状态与查重依据。查重未完成的候选保留待复核并说明原因，邮件工作簿可以为空。用户指定其他语言、模板或交付范围时按要求调整。

每批应核验产品事实和公开信息；评分不代表客户采购意向。具体步骤见 [SKILL.md](SKILL.md)，产品事实记录和发送要求见 `references/`。
